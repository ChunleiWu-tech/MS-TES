# MS-TES v10.1.0

This release provides the source code and registered inputs for the manuscript "Validity-domain auditing and engineering evidence reshape service-specific molten-salt rankings for thermal energy storage".

The release integrates an official database screen, a 142-candidate exact-composition thermophysical opportunity library, a frozen 15-candidate formal engineering registry, 20,000-draw uncertainty propagation, service-domain auditing, non-compensatory Pareto analysis and precedence-constrained evidence-action back-tracing.

The source-only archives exclude approximately 341 MB of reproducible generated outputs. All registered inputs, raw database archives, provenance ledgers, configuration, deterministic seed rules and model code required to rebuild those outputs are included. The post-processing package generates six main and twelve supplementary figures and passes 42 scientific, semantic and visual checks.

Important scope boundary: candidates outside the frozen engineering registry are screened as thermophysical opportunities but receive no formal-selection or formal-failure outcome.
